ConciseClaude

Claude Code that gets to the point. Same work, a third of the words.

Install

claude plugin marketplace add drknowhow/ConciseClaude
claude plugin install conciseclaude@conciseclaude

Start a new session and it is on, for Opus, Sonnet and Haiku.

What you get

Answer first

Every reply opens with the result. No preamble, no recap, no closing offer.

Depth when you ask

Say "in depth" and you get the full treatment. Errors, risks and safety steps are never cut.

Measured

A meter checks every reply and nudges Claude when it runs long. Code arrives without narration.

Benchmarked

Default against ConciseClaude 6.2 on Opus 5.5, Sonnet 5.5 and Haiku 5.5, every case run twice, single-turn replies graded blind against key-point checklists. On Opus, replies came out 64% shorter, cost fell 23% and answers arrived 34% sooner, while covering 87% of key points against 98% for the default. Sonnet cost fell 13%; Haiku broke even.
